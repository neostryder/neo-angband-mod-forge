# Settings reference

These rules are read when the mod starts. They are not live hooks, so changing any of them requires a reload.

| Flag | Default | What it does | Reload required |
| --- | --- | --- | --- |
| `builder.showTab` | on | Adds Build a mod to the Game menu. | Yes, startup side. |
| `builder.keepDrafts` | on | Saves unfinished workshop mods in install settings. | Yes, workshop startup side. |
| `builder.cheatSpawn` | off | Enables the Test panel's debug based test setup. | Yes, workshop startup side. |
