# Terms of Use for ModForge

Effective date: 2026-08-23.

ModForge is an optional mod folder that runs inside Neo Angband, with no separate hosted service. It provides an in-game workshop for creating and inspecting mod files. It can keep unfinished drafts in local game storage when the draft-retention setting is enabled, load a content mod for the current game session, and build a downloadable zip file when the player chooses to save one. It does not publish a created mod, install it permanently into a library, create an account, or send a draft to a project-operated service.

A session-loaded mod can change a character even after the session copy of the mod is forgotten, and testing features can stop the current session from being saved. The player is responsible for deciding whether to test with a character, saving a finished mod outside browser storage, reviewing the files ModForge creates, and assigning an appropriate licence and permissions before distributing anything made with it. ModForge does not clear third-party intellectual-property, content, licence, or compatibility obligations for a mod it emits.

Its shipped manifest does not declare network access, and its shipped plugin code makes no network requests. A zip the player creates stays a local download unless the player separately uploads, shares, or installs it. The core Neo Angband Terms and Privacy Policy cover the shared host behavior, including local storage, network requests, and third-party services.

The GPL v2 or Angband licence in `LICENSE.md` governs ModForge's covered source and materials. That licence does not determine rights in a player-created mod or third-party material included in one. ModForge is provided as available and without a promise that its suggestions, checks, output, or preview are complete, correct, compatible, safe, or fit for a particular purpose, to the extent permitted by applicable law.

Use must comply with applicable law, the applicable licences, and the Neo Angband Terms. Project participation is subject to the shared Code of Conduct.
